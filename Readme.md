# Number Guessing Game

## Overview

A console-based Number Guessing Game built in Java to practice and apply core programming concepts learned during my Java fundamentals journey.

The player selects a difficulty level and attempts to guess a randomly generated number within a limited number of attempts. The game provides hints, tracks previous guesses, validates user input, calculates scores, maintains the highest score achieved during the session, and allows replaying multiple rounds.

## Features

* Multiple difficulty levels
* Random number generation
* Hint system
* Score calculation
* Highest score tracking
* Previous guess history
* Input validation
* Limited attempts
* Replay functionality
* Win/Lose game states

## Gameplay

1. Select a difficulty level.
2. The game generates a random number.
3. Enter guesses until you find the correct number or run out of attempts.
4. Receive hints after incorrect guesses.
5. View your score and guess history.
6. Track the highest score achieved during the session.
7. Choose whether to play again.
